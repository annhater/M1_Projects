# M1 Projects

A collection of coursework, exercises, and personal projects completed during the first year of a master's program. The repository brings together work in scientific Python, bioinformatics, machine learning, chemoinformatics, molecular modeling, and web development.

## Projects

| Folder | Topics and contents |
| --- | --- |
| [`adv_md/`](./adv_md/) | Molecular modeling work, including a docking-analysis notebook and a Python simulation of a Monte Carlo search over an energy landscape. |
| [`ai_2/`](./ai_2/) | Artificial-intelligence coursework: neural-network and CNN exercises, image-classification notebooks, and sequence/protein-structure learning experiments. |
| [`chemoinfo/`](./chemoinfo/) | Chemoinformatics tutorial material using RDKit, including molecular descriptors and fingerprints. |
| [`python_1/`](./python_1/) | Introductory Python exercises and small scripts, including a GC-content calculation. |
| [`python_2/`](./python_2/) | NumPy and Python exercises, sequence analysis, PDB structure processing, transmembrane-region extraction, and a genome-comparison project. Includes notebooks, source data, and some course correction materials. |
| [`web_dev/`](./web_dev/) | HTML, CSS, and JavaScript exercises, plus [`bookclub_web/`](./web_dev/bookclub_web/), a multi-page book-club website. |

## Getting started

This repository is a set of independent projects rather than one installable application. Browse to a project folder to explore its notebooks, scripts, and data files.

- Open `.ipynb` files in Jupyter Notebook, JupyterLab, or VS Code.
- Run Python scripts with Python 3 from their project directory. Some scripts expect an input data file or command-line argument; check the script or notebook before running it.
- Open `web_dev/bookclub_web/index.html` in a browser to view the book-club site. The web exercises in `web_dev/` are separate examples.
- Dependencies vary by project. Scientific notebooks and scripts may require packages such as NumPy, pandas, Matplotlib, or RDKit; install the dependencies needed by the specific project in your chosen Python environment.

## Repository notes

The notebooks and exercises are preserved as project work, so organization, completeness, and execution requirements can vary. Data files are included alongside the exercises that use them where applicable.
